### Key Technical Notes
- Frontend build must run from monorepo root: `npx vite build frontend` (not from frontend/ directory)
- CDK uses depsLockFilePath to point to root package-lock.json (avoids pnpm-lock conflict)
- Backend uses crypto.randomUUID() (built-in Node.js 20, no uuid package needed)
- DynamoDB single-table design with PK=PROJ#{id}/ISSUE#{id}, SK=METADATA/ISSUE#/SPRINT#/BOARD#
- GSI1 for listing (PROJECTS/PROJ#{projectId}), GSI2 for status queries, GSI3 for search
